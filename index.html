  • Feature Branching: Every HTML page is developed independently on its own branch.
  • Pull Requests & Code Reviews: Changes are reviewed by teammates before merging into main.
  • Conflict Resolution & Revert: Hands-on practice with merge conflicts and safe commit reversion.
  • Documentation & Release: Full project documentation in Markdown and deployment via GitHub Pages.
